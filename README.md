# TA Club (TA अर्निंग क्लब) 🏆

Official Gaming & Lottery Platform built with React 19, TypeScript, Tailwind CSS, and Vite.

## 🚀 Features

- **WinGo Color Prediction**: 30s, 1m, 3m, 5m live timers (Red, Green, Violet, Numbers, Big/Small)
- **Aviator Crash Game**: Real-time airplane flight with cash-out and multiplier curve
- **K3 Dice Lottery**: 3-dice roll with totals, triples, and sum bets
- **Mines Game**: 5x5 gem grid with cash-out anytime
- **Slots**: Popular slot machine games (Fortune Gems, Super Ace, Crazy 777)
- **Official Paytm QR Deposit**: Merchant Surajaram (`surajaram01@ptyes`, Canara Bank - 2617)
- **First Deposit 50% Bonus**: 100 + 50 = ₹150, 500 + 250 = ₹750
- **Daily Check-in**: 7-Day login calendar bonus
- **Transaction History**: Real-time status tracking (`Pending ⏳`, `Success ✓`, `Failed ✕`) with digital receipts
- **Master Admin Control**: Discreet 5-tap trigger with PIN `DMD999` and 10 influencer demo accounts

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Deployment

The app is ready for instant deployment to:
- **Vercel**: Import repository -> Framework: Vite -> Deploy
- **Netlify**: Connect repo -> Publish directory: `dist`
- **GitHub Pages**: Build outputs to `dist/` with relative asset paths configured (`base: './'`)
